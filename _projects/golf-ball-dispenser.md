A dispenser that holds a column of golf balls and releases exactly one when a
button is pressed.

## The problem

Single-item dispensing is a timing problem disguised as a simple one:

- **Release one, hold the rest.** The instant a ball leaves, the next one is
  already moving. Something must block it before it follows.
- **Spring force has to work across a changing column.** A full dispenser pushes
  harder than a nearly empty one, and the release must behave the same at both
  extremes.
- **A golf ball is heavy and hard.** It does not deform to squeeze past a gate,
  so clearances are absolute — too tight and it jams, too loose and two escape.
- **The body is a moulded part** with a spring and a pin inside, which means
  every internal feature has to be reachable by tooling.

## The approach

- **Gate geometry sized to one ball diameter**, so the retaining feature engages
  the next ball before the released one has cleared — sequence built into the
  shape rather than into timing.
- **Spring specified for the empty case.** Sizing for the weakest condition
  guarantees feed at the end of the column; the full-column case is then checked
  for excess force rather than the other way round.
- **A pin as the moving element**, keeping the mechanism to one sliding part
  driven by the button, with no linkage to bind.
- **Everything drawn.** Each part carries its own production drawing, so the
  moulder and the assembler work from the same dimensioned set.

## The result

Two design iterations, ending with a complete assembly and a per-part drawing
package including dimensioned PDFs.

## Where this applies

Dispensers of all kinds — balls, tablets, caps, fasteners. The mechanism is
always the same question: what stops the next one?
